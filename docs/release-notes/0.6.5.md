**New: Palaver respects mute in Teams and Slack.** While you're muted in the call Palaver is recording, your microphone isn't kept; the track gets silence instead, so a conversation in the room next to you doesn't end up in the transcript. The others in the call are recorded as before. In-person recordings are never affected. You can turn this off under Settings → Recording.
- Teams: Palaver reads Teams' mute button. macOS asks once to allow Palaver under **Privacy & Security → Accessibility**; please allow it. Without it, Palaver falls back to Teams' log, which is up to ~30 s late, and Settings shows how to allow it.
- Slack: muted is when Slack releases the microphone, or Slack's own mute button when Accessibility is allowed.
- While you're muted, the menu bar icon shows a slashed mic, and the recording's page and Today say "Your mic is muted in Teams: not recorded". If Palaver can't tell whether you're muted in Teams, the recording's page says so and links to the Accessibility setting.
- Palaver reads Teams' log only when the mute button can't be read, so macOS no longer asks to let Palaver "access data from other apps" when the button works.
